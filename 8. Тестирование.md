# 8. Тестирование

## Статус: проведён полный аудит (14.09–15.09.2026)
Правки от 16.09 (см. ниже) автоматическим аудитом не покрыты, но 19.09 пользователь проверил их вручную: всё в порядке.
10 параллельных агентов проверили сайт по разным направлениям (навигация, форма/цена, i18n, данные машин, доступность, производительность, SEO, сборка/линт, вёрстка) + один агент с реальным headless-браузером (Playwright), который проскроллил сайт и покликал по кнопкам как настоящий пользователь, на мобильном и десктопном экранах.

## Виды тестирования
- [x] Функциональное (навигация, форма бронирования, калькулятор цены)
- [x] Юзабилити (мобильная вёрстка, доступность форм)
- [x] Визуальное (реальные скриншоты mobile/desktop через Playwright)
- [ ] Нагрузочное — не применимо (демо-сайт)
- [x] Безопасность/доступность (a11y-аудит)

## Как повторить аудит в будущем
Полные отчёты 10 агентов сохранены в `scratchpad/audit/*.md` этой сессии (временная директория, не в репозитории). При следующем большом тестировании — тот же подход: параллельные агенты на код-ревью + один агент с Playwright на реальный клик/скролл/скриншот.
