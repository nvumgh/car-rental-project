Это не пересказ этих файлов, а выжимка того, что нужно непосредственно для генерации макетов.

## О проекте
Демо-версия современного лендинга компании по аренде автомобилей в Дубае (ОАЭ). Смешанный флот: люкс/спорткары + средний класс/эконом. Аудитория — туристы (короткая аренда) и резиденты ОАЭ (аренда вместо покупки). Ключевая идея: клиент выбирает машину, видит её "как живую" через анимированную галерею, сразу понимает финальную цену и оформляет заявку за минуту — без переписки и скрытых платежей.

## Целевая аудитория
- Туристы: бронируют на 1–10 дней, важна прозрачная цена, доставка, поддержка на своём языке (в т.ч. русский).
- Резиденты ОАЭ: аренда на месяц вместо покупки, тест модели перед покупкой, важна гибкость условий.

## Стиль и настроение
**Единый чёрный премиальный стиль по всему сайту** (важное уточнение: изначально рассматривался вариант "светлый для эконома + тёмный для люкса", но по итогам просмотра демо от этого отказались — светлый фон выглядел слишком просто, а главное фото хорошо перетекает в чёрный фон каталога). Итог — весь сайт тёмный, независимо от класса машины.

Формулировка настроения — **"Тихая элегантность"**: статус без крика, "дорого и спокойно", как бизнес-лаунж в аэропорту. Никаких кричащих/неоновых цветов, никакого золота — сдержанность сама по себе часть впечатления премиальности.

## Типографика
- **Заголовки/крупные акценты**: Playfair Display (изящный, слегка классический serif) — используется для брендового лого-текста, заголовков секций, названий моделей авто.
- **Основной текст/UI**: Inter (чистый, современный sans-serif) — тело текста, кнопки, лейблы, навигация.
- Оба шрифта — бесплатные Google Fonts.
- Заголовки — крупные, выразительные (hero-заголовок на десктопе — вплоть до 72px), не мелкий убористый текст.

## Общие UI-принципы
- **Bento-подобная модульность**: карточки разного размера с фото/ценой/текстом, а не сплошной текст.
- **Плавные микроанимации при скролле**: блоки появляются с лёгким смещением снизу вверх и нарастанием непрозрачности (не резко).
- **Hero на всю ширину/высоту экрана** с крупным фото машины, тёмным градиентом снизу (для читаемости текста) и крупным заголовком поверх.
- **Единая, спокойная анимация** для показа машины (переход между 3–5 ракурсами фото + лёгкая анимация появления/"выезда"), без претензии на полноценный фотореалистичный 360°-спин.
- Скругления карточек — крупные (rounded-2xl, "мягкие" углы), тонкие полупрозрачные бордеры вместо жёстких линий.
- Мобильная версия — приоритет, не "довесок" (большинство туристов смотрят с телефона).

## Структура сайта и экраны для дизайна

### Экран 1 — Главная страница
1. **Тонкий баннер сверху**: "Демо-версия сайта: модели, фото и цены — иллюстративные, не привязаны к реальному автопарку." (мелкий текст, светлая полоса на тёмном фоне).
2. **Шапка**: логотип-надпись "RENTX" (Playfair Display), навигация (Каталог / Преимущества / Отзывы / Вопросы), переключатель языка RU/EN справа.
3. **Hero-блок**: полноэкранное фото люксовой машины (сейчас — Rolls-Royce Cullinan анфас, тёмный интерьер двора), градиент от тёмного низа, поверх — надпись "АРЕНДА АВТО В ДУБАЕ" (эйбрроу), крупный заголовок **"Выбираешь машину — видишь её как живую"**, подзаголовок **"Прозрачная цена без скрытых платежей, эконом и люкс в одном каталоге, бронирование за минуту — без звонков и переписки."**, кнопка **"Смотреть каталог"**.
4. **Каталог**: фильтры-пилюли (Все / Люкс / Средний класс / Эконом), сетка карточек машин (3 в ряд на десктопе). Карточка = фото 4:3, бейдж класса поверх фото, название модели, короткий слоган, цена "от X AED / сутки".
5. **Блок преимуществ** (4 карточки в ряд): "Честная цена сразу", "Лицензированная аренда", "Эконом и люкс — один стандарт", "Поддержка на вашем языке" (тексты см. ниже).
6. **Отзывы** (3 карточки в ряд): текст отзыва + имя, модель авто, дата.
7. **FAQ** (аккордеон, 4 вопроса): документы/IDP, возраст водителя, депозит, состав цены.
8. **Футер**: название бренда, короткая заметка о демо-статусе, отметка языков RU/EN.

### Экран 2 — Страница модели авто (ещё не задизайнена в коде, следующий этап)
Отдельная страница на каждую модель (не модалка). По ТЗ должна содержать:
1. Hero-блок модели с анимацией "выезда" авто при открытии.
2. Галерея из 3–5 фото с плавным переходом между ракурсами.
3. Блок характеристик: класс, места, багажник, трансмиссия, топливо.
4. Переключатель тарифа **"сутки / месяц"**.
5. Прозрачный калькулятор итоговой цены (без скрытых платежей).
6. Отзывы, релевантные именно этой модели.
7. Форма бронирования (модель, тариф, даты, контакт, комментарий) с кнопкой отправки заявки.
8. Экран/сообщение подтверждения после отправки.

### Преимущества
1. **Честная цена сразу** — Итоговая стоимость — сутки, неделя, месяц — видна до заявки. Без «уточним при встрече».
2. **Лицензированная аренда** — Работаем по правилам RTA Дубая — легальность и прозрачные условия договора.
3. **Эконом и люкс — один стандарт** — Неважно, какой класс машины — сервис, подача и качество общения одинаково высокие.
4. **Поддержка на вашем языке** — Русский и английский — отвечаем и оформляем бронь на удобном вам языке.

### FAQ
1. **Какие документы нужны для аренды?** — Паспорт и водительские права. Для граждан ряда стран (включая Россию, Индию, Китай) требуется международное водительское удостоверение (IDP) вместе с оригиналом прав.
2. **Какой минимальный возраст водителя?** — От 21 года для стандартных авто. Для люксовых и спортивных моделей — от 25 лет, для некоторых суперкаров — от 30 лет.
3. **Как работает депозит?** — Депозит блокируется на карте на время аренды и возвращается после проверки штрафов и платежей за платные дороги (Salik). Точный срок возврата указывается при бронировании.
4. **Что входит в стоимость?** — Базовая страховка включена в цену. Итоговый расчёт на странице модели показывает все компоненты стоимости — без скрытых доплат.

Из конкурентного анализа ([1. Разведка](1.%20Разведка.md)) — что стоит взять за визуальный ориентир:

## Технические ограничения
- Сайт строится на React + Tailwind CSS + Framer Motion (для анимаций) — макеты должны быть реализуемы этим стеком, без сложной кастомной 3D-графики.
- Никакого полноценного фотореалистичного 360°-спина — вместо этого 3–5 фото-ракурсов с анимацией перехода.
- Обязательна мобильная адаптация (макеты — минимум для desktop и mobile).
- Изображения машин — сжатые JPEG, не более ~650 КБ каждое (учитывать в макете, не закладывать эффекты, требующие огромных исходников).

## Чего избегать
- Светлого/белого фона — решение пересмотрено, весь сайт тёмный.
- Ярких/цветных акцентных цветов (золото, неон, кислотные цвета) — только монохромная графитово-серебристая палитра.
- "Шаблонного", как у большинства конкурентов, вида (мелкий текст, плотная вёрстка, отсутствие воздуха) — сайт должен визуально выделяться.
- Перегруженности анимациями в ущерб скорости — анимации сдержанные, не мешают быстро дойти до бронирования.
