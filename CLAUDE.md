# Git

Веди Git всегда: при каждой удачной версии проекта (значимое изменение, новый конспект, обновлённый документ, исправленная ошибка) делай коммит с понятным сообщением, чтобы были версии и можно было откатиться.

Если нужна новая линия экспериментов — создавай ветку, не трогая рабочую версию в `main`.

Это локальный репозиторий. На GitHub не отправляй — здесь просто история изменений на компьютере (как и рекомендовано в уроке «Git как фундамент»). Отправляй только если прямо попросят.

Примечание: `site/` — отдельный самостоятельный репозиторий (car-rental-landing), поэтому он в `.gitignore` и не отслеживается отсюда.
